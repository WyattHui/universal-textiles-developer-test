### Dependencies
* Composer (https://getcomposer.org)

### Development
* Install back-end

    * Copy `.env.example` to `.env`

    ```
    composer install
    ```

* Install and start front-end

    ```
    npm install
    npm run dev
    ```

* Start

    ```
    php artisan serve
    ```

### Deployment instructions
* Build

    ```
    npm run prod
    ```
